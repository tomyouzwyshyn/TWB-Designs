Shot prompts for every photo and video on the site

26 slots across four pages, 14 of them video. Each slot lists the file name the site is waiting for, what the shot needs to show, and prompts ready to paste.

  • ImagesPaste the prompt into Midjourney, Flux, Imagen or Firefly and set the aspect ratio shown on the card.
  • VideoGenerate the photo from the prompt and save it with the .jpg name shown. It fills the slot on the site right away. Then give the same photo to Runway, Veo, Kling or Sora with the motion line and save the result as the .mp4, which replaces the photo automatically.
  • AvoidPaste into the negative prompt field, or add it after the prompt as "Avoid: …".
  • Save asUse the exact file name and drop it in assets/media/. The site swaps it in automatically.
